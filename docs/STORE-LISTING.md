```
Reading glasses for the web.

Install Aletheia once. Noisy pages get quieter. You stay in control. Nothing leaves your device. Free forever — no account, no subscription, no AI in the loop.

WHAT IT DOES
• Hides common summary panels and overview boxes (the kind that sit on top of search and articles)
• Collapses likely autogenerated clutter and side rails
• Built-in local site packs for common search, video, discussion, and news pages
• On-page controls: On / Off, this site, What changed?, Show page as-is
• Optional calm reading layout (Alt+Shift+L)
• Power users can add their own CSS rules in Options — optional, not required

HOW IT WORKS
Aletheia is not an AI product. No remote model. No remote classifier. It uses conservative, on-device pattern matching (selectors and site packs) in your browser. Settings stay in chrome.storage.local on this device.

You can undo anytime. She is allowed to miss. Restraint is part of trust.

WHAT IT IS NOT
• Not an ad blocker — ordinary ads are not the target
• Not an AI detector — it does not label people, posts, or “bots”
• Not a cloud service — no telemetry, no sync, no account

PRIVACY
No user data is collected or sent. Ever.

For the people.
```

## Permissions — reviewer-facing copy

**`storage`**
Saves your defaults, per-site choices, custom rules, and UI preferences locally on this device.

**`activeTab`**
When you click the Aletheia toolbar icon, the launcher reads the active tab’s hostname so it can show the right page context and open on-page controls.

**`<all_urls>` (host permission)**
Lets Aletheia run a local content script on pages you visit so it can hide or collapse elements in your browser. Aletheia does not exfiltrate page content.

**Background service worker**
Routes local messages only (open Options, keyboard shortcut for reading layout). No network connections.
