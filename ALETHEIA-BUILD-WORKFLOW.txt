ALETHEIA BUILD WORKFLOW
=======================
Status: ACTIVE (2026-06-27)
Companion: ALETHEIA-VISION.txt
Covenant: Vesper decides · Narcissus structures · builds pass the prism
Model: Free forever · For the people · Local-only · Simple on the outside


PURPOSE
-------
Logical workflow for building Aletheia from v1.0.4 toward the agreed vision.
Engine before face. Reinforce before expand. Clarity Layers only after v1.1–1.3 are solid.


THE MASTER LOOP (EVERY SESSION)
-------------------------------
  1. INTENT      Vesper states what and why
  2. CORDIS      Narcissus: which tier? pollutes Core? Filter laws?
  3. IMMEMOR     Truth check — no hype, no certainty theater
  4. BUILD       Code, docs, local files — minimal scope
  5. EXPOSED     What's done, stubbed, risky — plainly
  6. SHIP        Vesper deploys, publishes, versions
  7. ADMIRE      Stop. Don't claim arrival. Reinforce before expand.


PRE-FLIGHT (60 SECONDS — EVERY CHANGE)
--------------------------------------
  1. Which tier — Core, Filter, or Application?
  2. Galvenais — still local-only? No telemetry creep?
  3. ImmemorSui — honest copy? No "AI detected" / guaranteed claims?
  4. North star — normal person, less stress, no power-user homework?

  Yes on all four → proceed.
  No → relocate to Options, defer, or cut.


CORDIS PLACEMENT GUIDE
----------------------
  CORE (do not pollute)
    - DOM heuristics, reading-root scoring
    - Site-profile selector matching logic
    - Change-tracking counters (what was hidden/collapsed)
    - Future: layer detection heuristics (Clarity Layers)

  FILTER
    - Site packs (host-specific selectors)
    - SPA resilience (pushState, popstate, retry)
    - Conservative hide/collapse rules
    - Reversible undo / show-as-is
    - Permissions posture (local storage only)

  APPLICATION
    - Popup UI (Clarity ON/OFF, site choice)
    - "What changed?" drawer
    - Options page (power users)
    - First-run card, store copy, changelog
    - Reading layout shell (existing Alt+Shift+L)

DAY 1 — v1.0.5 KICKOFF (LOGICAL ORDER)
--------------------------------------
  Block 1 · BASELINE (Vesper)
    Open Chrome. Test v1.0.4 on:
      - Google Search
      - YouTube
      - Reddit
      - One major news article
    Note what still leaks through. This is the receipt for Day 1.

  Block 2 · SITE PACKS (Narcissus → Filter)
    Create shared/site-profiles.js
    Host-specific selectors for:
      - Google (AI Overviews, summary shells)
      - YouTube (summary / key-moments clutter)
      - Reddit (recap / summary blocks)
      - 2–3 major news hosts
    Wire into content.js applyBuiltins() or equivalent.
    Still local. No remote feed.

  Block 3 · SPA FIX (Narcissus → Filter)
    popstate / history.pushState awareness
    Debounced re-apply on DOM mutations (existing observer — strengthen)
    Short post-load retry window (YouTube, Reddit hydrate late)

  Block 4 · TRANSPARENCY (Narcissus → Filter + Application)
    Track per-page: hidden count, collapsed count, reasons (summary, clutter, custom)
    Lightweight "What changed?" panel or popup section
    "Show this page as-is" — session-only undo (does not wipe site memory)

  Block 5 · SIMPLE POPUP (Narcissus → Application)
    Collapse to:
      - Clarity ON / OFF (master switch)
      - This site: Clarify / Use default / Allow
      - [ What changed? ]
      - [ Show page as-is ]
      - Options → (custom rules, reading shortcut — power users)
    Move granular summary/clutter dropdowns to Options if needed.

  Block 6 · TEST PASS (Vesper)
    Run test matrix (below). Fix failures. Retest.

  Block 7 · SHIP PREP (Together)
    Bump manifest version
    Update CHANGELOG.md
    Reload unpacked in chrome://extensions
    Optional: Chrome Web Store submit when green


BUILD SEQUENCE (DEPENDENCY ORDER)
---------------------------------
  Baseline test v1.0.4
      → site-profiles.js
      → wire profiles into content.js
      → SPA hooks + retry
      → track changes per page
      → "What changed?" + show as-is
      → simplify popup UI
      → 4-site test matrix
      → pass? → version bump + changelog
      → fail? → fix → retest

  RULE: Site packs before popup polish. Engine before face.


TEST MATRIX (VESPER — ~15 MIN)
------------------------------
  Site            | Pass if…
  ----------------|--------------------------------------------------
  Google Search   | AI overview / summary shell hidden or collapsed
  YouTube         | Summary clutter quieted; survives scroll/nav
  Reddit          | Clutter collapsed; survives comment load
  News article    | Reading layout still works (Alt+Shift+L optional)
  Any site        | "Show as-is" restores page; Clarity OFF disables all

    ✗ Paywall bypass / ad blocking
    ✗ Store marketing rewrite (unless v1.0.5 is ready to submit)

    ✗ "AI detector" badges on people
    ✗ Remote AI / analytics / telemetry

  Yes → ship.
  No  → Options page or never.
