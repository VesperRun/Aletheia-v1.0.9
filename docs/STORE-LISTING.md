## Store description (detailed)

**Paste into Chrome Web Store description:**

```
Install Aletheia once. The web gets calmer. You stay in control. Nothing leaves your device.

Aletheia is a free, local-first Chrome extension for people who want less noisy pages—not another account, dashboard, or “AI detector.”

WHAT IT DOES
• Hides common AI summary panels and overview boxes
• Collapses or hides likely autogenerated clutter and side rails
• Built-in site packs for Google, YouTube, Reddit, and major news (BBC, CNN, NYT, Washington Post)
• Floating on-page controls while you scroll—Aletheia On/Off, Clarify / Default / Allow per site
• “What changed?” shows an honest count of what was hidden or collapsed
• “Show page as-is” pauses clarity for the current page only—restore anytime
• Clean reading layout (optional shortcut: Alt+Shift+L)
• Custom CSS rules for power users (Options → Rules & help)

HOW IT WORKS
Click the Aletheia icon for a small launcher. Full controls live on the page in a floating panel. Settings stay in chrome.storage.local on your device.

WHAT IT IS NOT
• Not an ad blocker—legitimate advertising is not Aletheia’s target
• Not perfect AI detection—conservative heuristics only; restraint is part of trust
• Not a remote service—no browsing telemetry, no cloud sync, no account

PRIVACY
No user data collected or sent. Ever. No Aletheia-operated backend required.

For the people.
```

## Permissions — reviewer-facing copy

**`storage`**
Saves your defaults, per-site choices, custom rules, and UI preferences locally on this device.

**`activeTab`**
When you click the Aletheia toolbar icon, the launcher reads the active tab’s hostname so it can show the right page context and open on-page controls.

**`<all_urls>` (host permission)**
Lets Aletheia run a local content script on pages you visit so it can hide or collapse elements in your browser. Aletheia does not exfiltrate page content.

**Background service worker**
Routes local messages only (open Options, keyboard shortcut for reading layout). No network connections.
