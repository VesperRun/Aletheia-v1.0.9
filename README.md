# Aletheia

Aletheia is a local-first Chrome Manifest V3 extension that helps users quiet AI-heavy websites by hiding common AI summary panels, collapsing likely AI clutter, and offering a clean reading layout.

Aletheia does **not** collect user data, does **not** send browsing data anywhere, does **not** use remote servers, and does **not** claim perfect AI detection. It gives users local controls in their own browser.

**For the people:** no user data is collected or sent. Ever. Aletheia is designed so the user's browser does the work. Settings and custom rules stay local. There is no account, no tracking profile, no telemetry pipeline, and no hidden data collection.

**Product truth:** Aletheia should miss some things. Its restraint is part of its trust: it uses conservative local patterns, avoids surveillance, and leaves final judgment with the reader.

## Product Principles

- Browser extension first.
- Local processing by default.
- Near-zero backend surface area.
- No account required.
- No user data collection.
- No browsing telemetry.
- No remote AI classifier.
- Minimal permissions.
- Per-site user control.
- Safe custom user rules.
- Conservative by design: miss some clutter before overclaiming certainty.
- Chrome Web Store friendly language.

## Features

- Hide common visible AI summary panels.
- Collapse likely autogenerated clutter.
- Clarify the current page, then click again to show it as-is.
- Toggle a clean reading layout.
- Set summary-panel and likely-clutter choices independently for each site or use your defaults.
- Add host-scoped custom CSS selector rules.
- Import and export local custom rules as JSON.
- Toggle reading layout with `Alt+Shift+L` by default.

## Local Development

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this `aletheia-extension` folder.
5. Reload the extension after code changes.

Use `dev/fixture.html` for a predictable manual test page. See `docs/TESTING.md`.

## Privacy Posture

Aletheia stores extension settings locally with `chrome.storage.local`. Page inspection and layout changes happen in the user's browser. See `PRIVACY.md` and `docs/TEXAS-PRIVACY-AND-AI.md`.
